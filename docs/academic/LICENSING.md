are not treated as proof of unrestricted downstream redistribution rights. Do not
label the whole project MIT, Apache, public domain or unrestricted open source
without resolving the actual rights. No new blanket LICENSE is added.

The original import manifest is historical: its “unchanged” status describes the
Phase 1 copy. Phase 4 subsequently added optional observed-team output to the
imported delta-stepping header/translation unit. The
[Phase 6 audit](../validation/phase6/evidence-audit.json) records current hashes and
that extension without overwriting original upstream hashes. Working algorithms
and upstream notices remain preserved during Phase 6; DynaGraph-HPC was not modified.

Before an unrestricted external distribution:

1. Obtain and retain an appropriate upstream license or explicit permission covering
   the imported source and intended use; involve the actual rights holders.
2. Choose a compatible license for the project's own contributions only after rights
   and obligations are understood, preserving required notices and attribution.
3. Review the separately installed runtime/dashboard/authoring dependencies and
   their distribution notices for the intended packaging; dependency availability
   does not license the imported engine.
4. Add the actual grants/notices to version control and update the report's release
   readiness assessment. Do not backdate or fabricate permission.

The academic package is technically prepared for a qualified demonstration, while
licensing remains an unresolved release-readiness condition. This document records
provenance and decisions; it is not a substitute for an actual grant from a rights holder.
